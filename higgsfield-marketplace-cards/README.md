# 05 / Marketplace Cards

Create a coordinated set of product images shaped for marketplace listings.

**Reach for this skill when** a listing needs its main image, secondary product images, infographics, lifestyle cards, or A+ style modules. Marketplace rules and prompt templates are handled by the backend, so this workflow is intentionally separate from general product photography.

## Start here

- [Skill instructions](./SKILL.md) - choose the requested scope and provide product context.
- **Product Photoshoot** - for brand-led product imagery without marketplace requirements.
- **Generate** - for general-purpose image or video creation.
