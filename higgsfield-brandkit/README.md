# 04 / Brandkit

Build a connected visual identity, then carry it into the assets a brand actually needs.

**Reach for this skill when** the request spans a logo system, colors, typography, social graphics, packaging, signage, merchandise, presentations, or an editable brandbook. Start from the user's existing assets and lock approved decisions before expanding the system.

## Start here

- [Skill instructions](./SKILL.md) - stages, approvals, and deliverable routing.
- [Intake](./references/intake.md) - collect the brief and source assets.
- [Brand lock](./references/brand-lock.md) - preserve approved identity decisions.
- [Logo](./references/logo.md) - develop and export the logo system.
- [Palette](./references/palette.md) and [typography](./references/typography.md) - define the visual foundations.
- [Brandbook](./references/brandbook.md) - assemble the final identity guide.
- [QA and iteration](./references/qa-and-iteration.md) - review before delivery.
