# 09 / YouTube Thumbnail

Build a truthful, high-impact cover that makes the video's real subject easy to understand at a glance.

**Reach for this skill when** the user needs a YouTube thumbnail, Shorts cover, or vertical video cover. The workflow develops the concept before rendering, preserves supplied identities, and keeps edits focused.

## Start here

- [Skill instructions](./SKILL.md) - concept, references, variants, and delivery.
- [Thumbnail frameworks](./references/thumbnail-frameworks.md) - construct an honest information gap.
- [Text overlay bake](./references/text-overlay-bake.md) - add and review text overlays.
- **Generate** - create the video or general media, not its thumbnail.
