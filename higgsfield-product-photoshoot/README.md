# 03 / Product Photoshoot

Create polished product imagery for campaigns, catalogs, social posts, and brand storytelling.

**Reach for this skill when** the product is the subject: studio photography, lifestyle scenes, close-ups, banners, carousels, ad packs, virtual try-ons, conceptual CGI looks, or image restyling. The backend builds the mode-specific prompt; the skill should not replace that with a hand-written generation prompt.

## Start here

- [Skill instructions](./SKILL.md) - choose a mode, provide product context, and deliver the results.
- **Brandkit** - for a full visual identity rather than a single product image.
- **Marketplace Cards** - for marketplace-specific listing image sets.
