# 02 / Soul ID

Create a reusable identity reference so supported Higgsfield image and video generations can keep the same person recognizable.

**Reach for this skill when** the user wants a digital twin, a personalized character, or a face-consistent identity for later creative work. Soul training is a separate, one-time step; its `reference_id` can be used by the `higgsfield-generate` skill.
