# 06 / Websites

Go from a product brief to a complete web experience, from its design system to a verified deployment.

**Reach for this skill when** the user wants a website, web app, landing page, dashboard, or browser game. Start by choosing the product type (`website`, `app`, or `game`); each type has its own integration, design, and release rules.
