# 01 / Generate

Turn a creative brief into images, video, 3D assets, audio, or a finished creative analysis with the Higgsfield CLI.

**Reach for this skill when** you want a general-purpose generation workflow, an image-to-video edit, sound, an ad, or a Virality Predictor report. For a specialized workflow, start with the dedicated skill for brand systems, product photoshoots, marketplace cards, thumbnails, or websites.
