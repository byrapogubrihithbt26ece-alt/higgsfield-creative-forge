# 07 / Faceless Video

Turn a topic or source material into a finished narrated video with a coherent visual direction.

**Reach for this skill when** the user wants an explainer, documentary, illustrated story, picture-based video, or children's song video. First resolve the format and creative choices; generation and local assembly are separate stages.
